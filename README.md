# pyperf
Performative Python tools and findings

# Purpose
Create a toolkit to be used for assessing the performance of Python code (blocks, classes, files, programs).  

# Roadmap, Feature to Include
* Measure memory utilization/overhead during execution
* Build a tool that can create a deterministic performance measurement, one that isn't impact by system fluctuations
* Create a set of exemplar data files for benchmark testing
* Create static-analysis tooling that can identify low-hanging performance improvements and identify bottlenecks
* Create an interative CLI that will identify, propose, and implement fixes
* Functionality to measure improvement between 2 versions
